# OrbiLocale
C2-AV-IMN 寰境再製 OrbiLocale 多語系內容再製與文化轉譯代理引擎 for 中小企業跨境行銷、跨國自媒體
# 寰境再製（OrbiLocale）多語再製代理系統規格書

> **專案代號**：`OrbiLocale-Agent`  
> **PMO 倉儲對應**：`C3-AV-IMN-F` (`allview-intl-marketing-network-app`)  
> **上游行銷預售倉**：`C2-AV-IMN` (`allview-intl-marketing-network-presale`)  
> **所屬事業體 Domain**：`allview.today`（文化傳播／數位媒體／全視界）  
> **架構定位**：具備文化轉譯（Transcreation）、影音多軌重組與合規護欄之全自動化／半自動化多語在地重製代理人（Agentic Remanufacturing Engine）。

---

## 1. 系統使命與核心定位

**寰境再製（OrbiLocale）不是翻譯器，而是具備商業與文化洞察的內容再製代理。**

傳統翻譯工具僅針對字面進行符號轉換，忽視了市場慣用法、語氣層級、文化隱喻、頻道節奏與法規合規邊界。`OrbiLocale` 接收來源內容後，首先解構其商業意圖、產品核心賣點、語氣輪廓、目標受眾（TA）與使用場景，隨後以目標市場原生受眾的視角，重新撰寫文案、重新編排影音時間軌、重塑廣告利益點，產出可**直接上架、直接播放、直接投放**的在地化交付包。

## 2. 服務對象與輸入定義

系統設計嚴格隔離兩類商業情境的處理流程：

                    │          OrbiLocale 任務接收器                │
                    └──────────────────────┬───────────────────────┘
                                           │
             ┌─────────────────────────────┴─────────────────────────────┐
             ▼                                                           ▼
┌─────────────────────────┐                                 ┌─────────────────────────┐
│ 情境一：非跨國型企業官網 │                                 │ 情境二：自媒體影音創作者 │
│  - 本地官網介紹文案     │                                 │  - 成片影音 (MP4/MOV)   │
│  - 產品宣傳/解說影片    │                                 │  - 置頂文案/簡介/標題   │

### 情境一：不具備國際行銷網絡之中小企業（B2B / B2B2C）
*   **來源輸入**：本地母語產品官網文案（Markdown/HTML/CMS 匯出檔）、產品解說/展示影片（含原始音訊與畫面字幕）。
*   **再製目標**：產出符合目標市場搜尋引擎習慣（SEO）、消費心理與通路常態的官網在地化版本與區域影片發布包。
*   **核心要求**：
    1.  嚴格凍結產品物理事實、數據、價格與法規邊界。
    2.  允許依目標市場文化重新調整標題吸引力、賣點呈現順序（Pain-point priority）、生活化例證與行動呼籲（Call To Action, CTA）。

### 情境二：跨國發布自媒體創作者（Creator / MCN）
*   **來源輸入**：已完成剪輯之自媒體影音（含長影片或短影音 Shorts/Reels/TikTok）、原始口白軌、既有標題、影片簡介（Description）、置頂留言（Pinned comment）。
*   **再製目標**：將原片轉化為目標語系受眾能產生情緒共鳴的在地版本。
*   **核心要求**：
    1.  輸出完整三軌：目標語系發音之口白稿（Voice-over, VO）、精準時間戳字幕稿（Subtitles）、畫面動態文字提示稿（On-Screen Graphics, OSG）。
    2.  置入廣告在地化重構：廣告語、痛點轉換與利益承諾必須改寫為目標市場慣用語，嚴禁生硬照搬原產地流行語、方言梗或文化隱喻。

## 3. 語系白名單與防護邊界

本代理系統之核心邊界為**封閉式 8 大語系矩陣**，嚴禁自主擴充未列入之語系。

| 語系代碼 | 語言名稱 | 地理/文化基準 | 預設敬語/風格配置 |
| :--- | :--- | :--- | :--- |
| `zh-TW` | 繁體中文 | 台灣 / 香港文化圈 | 自然流暢、親切專業、符合現代書面語與在地詞彙 |
| `zh-CN` | 簡體中文 | 中國大陸數位生態 | 簡練直接、適配主流社群節奏、符合在地用語習慣 |
| `en-US` | 英文 | 國際通用（以北美為基準） | 價值導向（Outcome-driven）、行動明確、結構清晰 |
| `ja-JP` | 日文 | 日本商業/自媒體標準 | 嚴格區分です/ます調、商務敬語（謙譲/尊敬）、委婉禮貌 |
| `ko-KR` | 韓文 | 韓國數位平台 | 適配尊稱（하십시오體/해요體）、情緒張力飽滿 |
| `es-ES` | 西班牙文 | 西班牙及泛西語市場 | 熱情生動、重視互動感（Tú/Usted 依渠道定位） |
| `fr-FR` | 法文 | 法國/法語區文化 | 優雅精確、注重修辭美感與嚴謹邏輯（Vous/Tu 區隔） |
| `de-DE` | 德文 | 德語區（DACH）標準 | 條理分明、重視事實嚴謹度與精準複合詞彙 |

> **執行邏輯約束**：若來源輸入已為上述 8 種語系之一（設為 $L_{\text{src}}$），系統僅針對其餘被指定的 $N$ 種語系產出（$N \subseteq \{L_1, \dots, L_8\} \setminus \{L_{\text{src}}\}$），嚴禁輸出非白名單語系。

## 4. 六大再製執行守則（Remanufacturing Guardrails）

```
                     ┌───────────────────────────────────┐
                     │      來源輸入內容 (Source Content) │
                     └─────────────────┬─────────────────┘
                                       │
                                       ▼
                     ┌───────────────────────────────────┐
                     │ 守則一：事實萃取與防護錨定        │
                     │ (品名 / 規格 / 數據 / 法規零篡改) │
                     └─────────────────┬─────────────────┘
                                       │
            ┌──────────────────────────┼──────────────────────────┐
            ▼                          ▼                          ▼
┌───────────────────────┐  ┌───────────────────────┐  ┌───────────────────────┐
│ 守則二：語感文化在地化│  │ 守則三：影音三軌長度配速│  │ 守則四：商業廣告重構  │
│ (敬語 / 稱謂 / 節奏)  │  │ (VO / 字幕 / 畫面字)   │  │ (去俚語 / 重塑利益點) │
└───────────┬───────────┘  └───────────┬───────────┘  └───────────┬───────────┘
            └──────────────────────────┼──────────────────────────┘
                                       │
                                       ▼
                     ┌───────────────────────────────────┐
                     │ 守則五：零幻覺防線 (Anti-Hallucination)│
                     │ (嚴禁添加未列之功效/獎項/背書)    │
                     └─────────────────┬─────────────────┘
                                       │
                                       ▼
                     ┌───────────────────────────────────┐
                     │ 守則六：多語系隔離交付包          │
                     │ (含文化/法規需人工確認之 Flag 標註)│
                     └───────────────────────────────────┘
```

1.  **事實不可變更原則（Fact Invariant）**：
    *   品名、產品型號、技術規格、數值、價格、百分比、測試認證、免責聲明，建立不可竄改白名單（Immutable Fact Table）。重寫僅限於修辭與敘事架構，核心事實偏差率必須為 $0\%$。
2.  **文化語感重構原則（Cultural Transcreation）**：
    *   拒絕直譯。依目標市場習慣重設句子長短、幽默轉譯、敬語等級與受眾稱呼。日韓市場須特別校準社群距離感；德語區強調數據呈現邏輯；西語區強調場景共鳴。
3.  **影音三軌配速同步原則（Audio-Visual Alignment）**：
    *   每一支影片必須同時輸出三軌文件：
        *   **軌道 A（口白稿 VO）**：標註發音語速（CPS, Characters Per Second 或 WPM, Words Per Minute），長度必須與原片音訊時間差控制在 $\pm 5\%$ 內。超出時必須給出具體「建議剪輯點（Suggested Cut Points）」。
        *   **軌道 B（字幕稿 SRT/VTT）**：斷句符合目標語閱讀節奏，每行字幕長度不超過目標語視覺邊界。
        *   **軌道 C（畫面文字稿 OSG）**：原片動態圖卡、標題字之在地化轉譯，提示後製替換。
4.  **商業置入與廣告在地化（Commercial Adaptation）**：
    *   剝離來源市場專屬之內梗、諧音、政治指涉與次文化隱喻。將廣告重點重新映射到目標市場該品類的通用痛點（General Pain Point）與核心價值（Unique Selling Proposition）。
5.  **嚴格反幻覺防線（Anti-Hallucination Policy）**：
    *   **紅線**：絕不得為提升文案說服力而擅自增添來源不存在的「功效、臨床數據、獲獎紀錄、名牌背書或客戶名單」。
6.  **結構化分離輸出（Per-Locale Segregated Output）**：
    *   輸出包依語系完全獨立切分，每一語系包包含：標題（SEO/Click）、正文/口白稿、字幕稿、置頂文案、商業廣告適配稿，以及最重要的**「人工複核註記清單（Human Attention Flags）」**（揭示當地特定法規風險、文化敏感點）。

## 7. 功能需求矩陣（Functional Requirements）

| 需求代碼 | 模組名稱 | 規格細節說明 | 優先級 |
| :--- | :--- | :--- | :--- |
| `FR-OL-001` | 來源事實凍結器 | 解析輸入文字/語音，自動生成「不可變更事實表」（包含價格、尺寸、數據、保證條款）。重製文案若修改數值則判定失敗。 | **P0** |
| `FR-OL-002` | 八大語系白名單檢驗 | 嚴格阻絕不在清單內的第 9 種語系輸出請求；嚴格排除與來源語系相同之輸出以節省 Token。 | **P0** |
| `FR-OL-003` | 官網文案重構引擎 | 根據目標市場文化調整賣點排序。日德市場優先呈現技術原理與嚴謹規格；英美市場優先呈現投資報酬率（ROI）與痛點解決。 | **P1** |
| `FR-OL-004` | 影音三軌同步引擎 | 同步產出口白（VO）、字幕（SRT/VTT）與畫面動態字（OSG）。計算發音長度比，當目標語長度超過原軌長度 $\pm 5\%$ 時，自動輸出建議剪接時間點。 | **P0** |
| `FR-OL-005` | 商業置入廣告改編器 | 識別片中商業贊助段落，檢索目標市場該行業常見宣傳用語，自動替換來源地才懂的流行語、地名梗或網路俚語。 | **P1** |
| `FR-OL-006` | 嚴格防幻覺審查器 | 執行逆向校驗，禁止在目標語中出現來源未曾提及的「認證、獎項、功效宣稱、權威人士推薦」。 | **P0** |
| `FR-OL-007` | 人工複核註記生成器 | 針對各語系輸出自動分析在地特定法規（如日本藥機法/景表法、歐盟 GDPR/AI Act 警示標示）與文化敏感點，生成 Warning Checklist。 | **P1** |

## 8. 非功能需求（Non-Functional Requirements）

*   `NFR-PERF-01`：影音文本分析與單一語系三軌生成時長，針對 5 分鐘影音應於 90 秒內完成初步再製。
*   `NFR-ACCU-01`：關鍵數據（規格/金額/效能倍數）一致性比對通過率必須達到 $100\%$。
*   `NFR-SEC-01`：符合 `allview.today` 組織與 PMO 之資訊安全基準，來源商業機密文案與影音在推論過程中不得持久化於公開緩存，遵循本地零留存原則。
